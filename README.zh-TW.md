# Tavern Ledger · 酒館帳本 v1.0.0

[English](README.md) | 繁體中文

SillyTavern 的 OpenRouter 費用帳本，支援繁體中文與 English。

## 安裝

在 SillyTavern 開啟「**擴充功能 → 安裝擴充功能**」，貼上：

```text
https://github.com/mimi1055/price
```

安裝完成後重新整理頁面。

### 手動安裝

若內建安裝器無法使用，可在 SillyTavern 目錄執行：

```bash
cd public/scripts/extensions/third-party
git clone https://github.com/mimi1055/price.git
```

完成後重新整理 SillyTavern。

## 快速使用

1. 在 SillyTavern 設定一般 OpenRouter API Key，無須管理 Key。
2. 選擇「**Chat Completion → OpenRouter**」並正常產生一則回覆。
3. 開啟「**擴充功能 → Tavern Ledger · 酒館帳本**」查看帳戶資訊。
4. 按下「開啟帳本」查看今日、本週、本月及個別生成紀錄。
5. 費用尚未出現時，等待約 15 秒或按下手動查詢。

## 功能

- OpenRouter 回應完成後刷新餘額，15 秒後補查一次；進入擴充設定、展開選單或開啟帳本也會刷新，並保留手動查詢。
- 查看今日、本週及本月的已記錄支出。
- 逐筆明細每頁顯示 10 筆，可翻頁查看全部已保存紀錄；分頁不會刪除舊資料或縮小帳本檔案。
- 費用待確認的紀錄保留在逐筆明細，但不在總覽持續顯示提醒；每筆請求最多進行三次帳戶差額補查，重新開啟帳本不會重新補查。
- 記錄聊天室、模型、tokens、重抽與續寫費用。
- 帳本可匯出 XLSX 明細表，開啟時先看到逐筆明細（角色、聊天室、回覆與候選序號、模型、費用及 tokens），另有月份總覽與模型統計。可在免費試算表軟體查看和編輯；修改匯出的表格不會改動帳本，備份及匯入仍使用 JSON。聊天全文不會存入帳本，也不會匯出。
- 從 API 連線頁按「測試訊息」產生的 OpenRouter 請求會標記為「連線測試」，不再顯示為未關聯的聊天回覆。測試失敗且未取得費用時會標示待確認，不假設為零費用。
- 搜尋明細、定位回覆；偵測到回覆刪除時保留費用並標記。
- JSON 匯出／匯入；匯入上限 10 MB、20,000 筆，重複紀錄保留原資料。

## 相容性與支援範圍

| 環境或功能 | 支援狀態 |
| --- | --- |
| OpenRouter Chat Completion | 支援 |
| 其他 API 供應商／Text Completion | 不支援 |
| SillyTavern 1.17.0 費用記錄 | 支援 |
| SillyTavern 1.17.0 帳戶餘額查詢 | 不支援 |
| 群組聊天、批次候選 | 可記錄，但回覆關聯不保證完整 |
| 同一伺服器與同一使用者的手機／電腦 | 共用同一份帳本 |

目前只列出已確認的相容性結果；其他 SillyTavern 版本仍需實測。

## 資料保存與備份

- 帳本透過 SillyTavern 的每位使用者檔案功能保存在伺服器端，檔名為 `tavern-ledger-v2.json`，不使用瀏覽器資料庫。
- 同一 SillyTavern 伺服器、同一使用者登入的裝置會共用帳本；不同使用者的資料彼此分開。
- 避免在多個裝置上同時產生或匯入紀錄，以免發生同時寫入衝突。
- 更新或移除擴充不會主動刪除帳本檔案。若要搬移、重裝或清除資料，建議先從帳本匯出 JSON 備份。
- Railway 等託管環境必須持久化 SillyTavern 的使用者資料目錄，否則重新部署後帳本可能消失。
- 不保存 API Key 或聊天全文。匯出檔包含角色名、聊天室名及使用紀錄，分享前請確認隱私。

## 更新與移除

- **更新：**在 SillyTavern 的「管理擴充功能」中更新 Tavern Ledger，完成後重新整理頁面。
- **移除：**在「管理擴充功能」中移除擴充。帳本檔案不會由擴充主動刪除。
- **清除帳本：**先匯出需要保留的紀錄，再從該 SillyTavern 使用者的檔案目錄移除 `tavern-ledger-v2.json`。

## 常見問題

### 為什麼無法取得帳戶餘額？

確認 SillyTavern 已成功連接 OpenRouter。一般 API Key 仍可聊天及記錄每次生成費用；SillyTavern 1.17.0 無法使用帳戶餘額查詢。

### 為什麼帳本合計和 OpenRouter 帳戶用量不同？

OpenRouter 帳戶餘額與累計用量可能包含同帳戶在其他酒館、裝置或應用程式的消費；帳本合計只計算本帳本已記錄或匯入的明細。

### 為什麼費用顯示「待確認」？

供應商回應沒有帶回正式費用時，擴充會嘗試利用帳戶扣款差額補算。其他消費或扣款延遲可能使結果無法確認；待確認費用不會計入合計。

### 為什麼刪除聊天後費用仍存在？

帳本代表已經發生的 API 消費，因此刪除聊天不會刪除費用紀錄；可以定位到的回覆被刪除後，紀錄會保留並標記。

### 為什麼新費用沒有立即出現？

OpenRouter 的扣款資訊可能延遲。擴充會在回應完成後查詢，約 15 秒後再補查一次，也可以手動重新查詢。

### 為什麼 Railway 重新部署後資料消失？

請確認部署服務已將 SillyTavern 的使用者資料目錄設為持久化儲存。帳本存在伺服器的使用者資料中，臨時檔案系統在重新部署後會被清除。
