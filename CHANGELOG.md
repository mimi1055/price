# Changelog

All notable changes to Tavern Ledger will be documented in this file.

## 1.0.0

- Initial public release.
- Added OpenRouter balance and recorded spending summaries.
- Added per-generation model, token, regeneration and continuation tracking.
- Added searchable details, reply location and deleted-reply markers.
- Added JSON import and export with validation and duplicate protection.
- Added English and Traditional Chinese interfaces.
